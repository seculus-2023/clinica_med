Onde obter o arquivo
{% if instrucoes == 'cmed' %}
  1. Acesse o portal da ANVISA: gov.br/anvisa › Medicamentos › CMED › Preços (Listas de preços de medicamentos).
  2. Baixe a "Lista de preços de medicamentos — Preço Fábrica e Preço Máximo ao Consumidor" em formato planilha (.xls/.xlsx).
  3. Envie o arquivo aqui e escolha a alíquota de ICMS do seu estado.

São importados: substância, laboratório, CNPJ, código GGREM, registro ANVISA, EAN, produto, apresentação, classe terapêutica, tipo de produto, regime de preço, PF, PMC, restrição hospitalar e tarja (tarja preta/restrição marca como controlado).

A atualização é mensal: importe novamente para atualizar os preços (o registro é localizado pelo código GGREM/EAN).

{% elif instrucoes == 'sigtap' %}
  1. Acesse sigtap.datasus.gov.br › Tabela Unificada › Download (ou o FTP do DATASUS).
  2. Baixe o ZIP da competência vigente (ex.: TabelaUnificada_202611_v...zip).
  3. Envie o ZIP inteiro — o sistema lê tb_procedimento.txt usando o layout oficial.

São importados código, nome, complexidade, sexo, idades e valores SH/SA/SP. Procedimentos que saírem da tabela vigente são inativados.

Para TUSS/CBHPM ou tabela própria, envie um CSV com as colunas codigo;nome;valor.

{% elif instrucoes == 'interacoes' %}

Marque carregar a base inicial para incluir ~30 interações clinicamente relevantes (anticoagulantes, nitratos x inibidores da PDE5, ISRS x IMAO, estatinas x macrolídeos/azólicos, IECA/BRA x poupadores de potássio, opioides x benzodiazepínicos, lítio, digoxina, metotrexato, contraceptivos x indutores enzimáticos e outras).

Para ampliar, importe um CSV com substancia_a;substancia_b;gravidade;efeito;conduta. Use termos do princípio ativo separados por vírgula (ex.: ibuprofeno, naproxeno).

Ferramenta de apoio: não substitui bulas, compêndios licenciados nem a avaliação do prescritor/farmacêutico.

{% else %}

CID-11

  1. No site da OMS (icd.who.int), na área de downloads da classificação ICD-11 MMS, baixe a planilha "Simple Tabulation".
  2. Envie o arquivo (ZIP, .txt ou .xlsx — com as colunas Code e Title) escolhendo a versão CID-11.
  3. Também é aceito CSV codigo;descricao (ex.: tradução em português).

CID-10

  1. Acesse o DATASUS: datasus.saude.gov.br › CID-10 (arquivos em formato CSV).
  2. Baixe o CID10CSV.zip e envie aqui. São lidos CID-10-CATEGORIAS.CSV e CID-10-SUBCATEGORIAS.CSV.

Também é aceito um CSV com as colunas codigo;descricao (útil para CID-11 ou listas próprias).
