Como conectar

Evolution API (gratuita, você hospeda — recomendada): instale a Evolution API num servidor (Docker), depois em Configurações da clínica escolha o provedor Evolution API, informe a URL (ex.: https://whatsapp.seudominio.com.br) e a API key (AUTHENTICATION_API_KEY). A instância usa o nome {{ instancia }}. Volte aqui e leia o QR Code.

Z-API (serviço pago brasileiro): crie a instância no painel da Z-API, conecte o número por lá e informe a URL https://api.z-api.io/instances/SUA_INSTANCIA/token/SEU_TOKEN e o Client-Token da conta.

WhatsApp Cloud API (Meta): crie um app no Meta for Developers, adicione o produto WhatsApp, registre o número da clínica e informe o Phone Number ID (campo Instância) e um token permanente. Atenção: para iniciar conversas fora da janela de 24h a Meta exige modelos de mensagem aprovados.

Webhook: o sistema faz POST JSON {remetente, telefone, mensagem, clinica} na URL informada (para integrar com n8n, Make, um bot próprio etc.).
